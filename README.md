An enterprise-grade, high-performance software engineering portfolio and case-study platform built by **Umair Ul Hassan** (Full-Stack Software Engineer & Applied AI Specialist). 

Architected with Next.js 16, React 19, TypeScript, and Tailwind CSS 4, featuring comprehensive deep-dive system architecture teardowns, hardware integrations, and machine learning pipelines.

---

## 🚀 Featured Flagship Systems

### 1. [GardenMate Ecosystem](https://github.com/umairulhassancs/gardenmate)
- **Domain:** Spatial Augmented Reality & Applied Deep Learning Mobile Platform
- **Stack:** React Native, Expo SDK 54, PyTorch ViT-B/16, PlantNet Botanic API, Viro AR, FastAPI, Stripe
- **Highlights:** 12+ production modules, 60/40 Vision Transformer + PlantNet weighted ensemble decision pipeline, Viro React AR surface plane detection (*"Place Before You Buy"*), and automated Snap-to-Autolist camera cataloging.

### 2. [Vouch Platform](https://github.com/umairulhassancs/vouch)
- **Domain:** Secure QR Verification & Masked Privacy Commerce
- **Stack:** Next.js 15, TypeScript, MongoDB, Tailwind CSS, Leaflet.js, Canvas QR Engine
- **Highlights:** Zero-PII receipt routing, cryptographic QR token generation with HMAC tamper detection, dynamic 50-meter GPS proximity validation, and real-time merchant claim settlement ledgers.

### 3. [FinGo Mobile Commerce](https://github.com/umairulhassancs/FinGo)
- **Domain:** FinTech & Distributed Micro-Merchant Ecosystem
- **Stack:** React Native, TypeScript, Node.js / Express, PostgreSQL, Prisma ORM, Redis
- **Highlights:** Biometric multi-factor authentication, sub-50ms optimistic escrow transaction ledgers, dynamic merchant catalog sync, and native device haptic feedback.

### 4. [Evershine Academy ERP](https://www.evershineacadmey.com/)
- **Domain:** Enterprise Institutional Management & Biometric Hardware Integration
- **Stack:** Next.js 16, React 19, TypeScript, Prisma ORM, MySQL, NextAuth.js 5, Biometric Machine SDK, jsPDF
- **Highlights:** 14 integrated production modules, live on-premise fingerprint machine attendance synchronization, 7-role multi-campus RBAC isolation, atomic Prisma fee challan generation, and automated vector document printing (QR ID cards & certificates).

### 5. [Autonomous Neural Copilot (JON OS)](https://autonomous-neural-copilot.vercel.app/)
- **Domain:** Voice-Activated Autonomous AI Copilot & DSP HUD
- **Stack:** Vanilla Modern JavaScript (ES Modules), Vite 5, Groq LLaMA 3.3 70B, Groq Whisper Large v3 Turbo, Web Audio API, Firebase Cloud Firestore
- **Highlights:** Passive browser-level wake-word listening (*"Jon"*, *"Hey Jon"*), sub-200ms cloud speech-to-text, Web Audio API continuous RMS energy tracking with 1.8s conversational silence cutoffs, deterministic JSON tool dispatching, and cyber-glass audio visualizer HUD.

## 🛠️ Technology Stack & Engineering Standards

- **Core Framework:** Next.js 16 (App Router, Turbopack, React 19 Server & Client Components)
- **Type Safety:** 100% Strict TypeScript contracts across all domain entities and route params
- **Styling & Design System:** Tailwind CSS 4, Custom Obsidian Dark Tokens (`#0A0E17`), CSS Grid, Radial Atmospheric Ambient Lighting
- **Motion & Micro-interactions:** Framer Motion spring physics, fluid scroll progress telemetry, and device mockups (Browser & Mobile frames)
- **Static Optimization:** Full SSG pre-rendering (`generateStaticParams`) across all project case study routes

## 💻 Getting Started

### Prerequisites
- Node.js 18.18+ or 20+
- npm 9+

### Installation & Local Run
```bash
# Clone the repository
git clone https://github.com/umairulhassancs/Portfolio.git

# Navigate to directory
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
```
